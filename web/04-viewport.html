Ch 105:has() 選擇器 主專案目前 0 處 · 版本錨點

左右兩個方塊都是藍色嗎？
✓ 左右都藍 = 支援
✗ 左邊是灰色的 = 不支援

Ch 108dvh 單位 主專案用了 96 處 · 首要嫌犯

這一項不要比「左右一樣高」。 在有網址列的瀏覽器裡，dvh 和 vh 的值本來就會差一點，那是正常的。 要看的是左邊那條有沒有完全消失。

測試：height 12dvh
參考：height 12vh

左邊那條藍色長條還看得見嗎？
✓ 看得見 = 支援（比右邊矮一點是正常的）
✗ 完全不見了，那一格空空的 = 不支援
（也請看上面那行實測數值，左邊顯示 0px 就是不支援）

Ch 108svh 單位 跟 dvh 同一批實作 · 交叉驗證

測試：height 12svh
參考：height 12vh

同上，看左邊那條還在不在。
✓ 看得見 = 支援
✗ 完全不見 = 不支援
這一項的結果應該跟上一項相同（同一批實作）。
