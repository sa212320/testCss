Ch 79min() / max() 主專案用了 87 處

測試：min(90px, 100%)
參考：寫死 90px

左右兩條藍色長條一樣長嗎？（粉紅虛線框是容器，兩邊一樣寬）
✓ 一樣長，兩邊都沒有填滿虛線框 = 支援
✗ 左邊那條變長，把虛線框填滿了 = 不支援
max() 跟 min() 是同一批實作，結果會相同，所以不另外測。

Ch 79clamp() 主專案目前 0 處 · 交叉驗證用

測試：clamp(50px, 90px, 120px)
參考：寫死 90px

左右兩條藍色長條一樣長嗎？
✓ 一樣長 = 支援
✗ 左邊那條填滿了虛線框 = 不支援
這一項的結果應該跟上一項完全相同。若一項支援、另一項不支援，請務必回報，那代表引擎被改過。
