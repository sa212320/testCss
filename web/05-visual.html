這一頁大多沒有左右並排，請照每一項下面的文字判斷。第 1 項最簡單 —— 看到紅色就是不支援。

Ch 26linear-gradient 漸層 主專案用了 7 處

上面這個方塊是什麼顏色？
✓ 藍色由深到淺的漸層 = 支援
✗ 整塊都是紅色 = 不支援

Ch 53filter: blur() 主專案用了 9 處

測試：套了模糊
模糊測試 ABC
參考：沒套模糊
模糊測試 ABC

左邊的字有模糊掉嗎？（這一項左右應該不一樣，跟前面幾頁相反）
✓ 左邊模糊、右邊清楚 = 支援
✗ 左右都一樣清楚 = 不支援

Ch 55clip-path 主專案用了 4 處

測試：clip-path 切三角
參考：border 畫三角

左右兩個都是三角形嗎？
✓ 兩邊都是三角形 = 支援
✗ 左邊還是正方形 = 不支援

Ch 41mix-blend-mode 主專案用了 2 處

黃色和藍色重疊的那一塊，顏色有變深嗎？
✓ 重疊處變成偏暗的深綠色 = 支援
✗ 重疊處就是純藍色，把黃色完全蓋掉 = 不支援

Ch 76backdrop-filter 主專案目前 0 處 · 版本錨點

白框裡面的斜條紋，比框外面模糊嗎？
✓ 框裡的條紋是霧的、糊掉的 = 支援
✗ 框裡的條紋跟框外一樣清楚 = 不支援
如果這一項連斜條紋都看不到，代表第 1 項的漸層也是壞的，那這一項就不用判讀了。
